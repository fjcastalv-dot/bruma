# bruma · Respira. Relaja. Crece.

Landing page interactiva para **bruma**, el shampoo aromaterapéutico que convierte tu ducha en un ritual de calma.

## 🌿 Características
- **Ritual de respiración guiada**: Ejercicio interactivo 4-4-4 con animaciones fluidas.
- **Aromaterapia botánica**: Selección interactiva de notas olfativas (Eucalipto, Lavanda, Vetiver).
- **Diseño sensorial**: Tipografías seleccionadas (*Cormorant Garamond* y *DM Sans*), soporte nativo para modo oscuro y accesibilidad (`prefers-reduced-motion`).
- **Autónomo y ligero**: HTML5, CSS y JavaScript sin dependencias externas pesadas.
